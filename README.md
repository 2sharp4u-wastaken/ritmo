# ריתמו · מאמן התיפוף

אפליקציית ווב (PWA) שמאזינה למיקרופון, בודקת כל מכה ומובילה את הילד במסלול של 12 שלבים עד פרדידל עם אקצנטים.

## הכי מהיר: קובץ אחד
`dist/ritmo.html` עובד גם בלחיצה כפולה במחשב (Chrome / Edge). כדי להעלות לאתר, אפשר להעלות רק אותו (בשם index.html).

## העלאה לאוויר (חובה https כדי שהמיקרופון יעבוד)
**GitHub Pages (חינם וקבוע):**
1. github.com ← New repository ← שם כלשהו, Public.
2. "uploading an existing file" ← גוררים את כל הקבצים והתיקיות מהתיקייה הזו ← Commit.
3. Settings ← Pages ← Branch: main, תיקייה / (root) ← Save.
4. אחרי דקה הכתובת מופיעה למעלה: https://<user>.github.io/<repo>/

**Netlify Drop:** גוררים את התיקייה ל-app.netlify.com/drop. כדי שהאתר יישאר, צריך חשבון חינמי.

## בטלפון/טאבלט
פותחים את הכתובת, מאשרים מיקרופון, ו"הוסף למסך הבית" כדי לקבל אייקון ומסך מלא. עובד גם בלי אינטרנט אחרי הפתיחה הראשונה.

## בדיקה מקומית
`python3 -m http.server 8000` בתיקייה, ואז http://localhost:8000
